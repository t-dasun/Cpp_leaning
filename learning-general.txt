A calling convention specifies how function parameters are passed, how return values are returned, and who is responsible for cleaning the stack during a function call.
cdecl      -> common C/C++ convention | arguments are usually passed through the stack, and the caller cleans the stack.
stdcall    -> often used in Windows API
fastcall   -> passes some arguments in registers
thiscall   -> used for C++ member functions, especially older MSVC
pascal     -> older convention
syscall    -> system call convention
-------------------------------------------------------------------------
__fastcall, the compiler tries to pass some arguments using CPU registers instead of the stack, so function calls may be faster.
int __fastcall add(int a, int b) {
    return a + b;
}

struct student {	
    char a;  // 1 byte
    char b;  // 1 byte
    int c;   // usually 4 bytes
};
char a  -> 1 byte
char b  -> 1 byte
padding -> 2 bytes
int c   -> 4 bytes

struct student {	
    char a; // 1 byte
    int c;  // 4 bytes
    char b; // 1 byte
};
char a   -> 1 byte
padding  -> 3 bytes
int c    -> 4 bytes
char b   -> 1 byte
padding  -> 3 bytes

Why  3 bytes padding?

The whole struct must usually be aligned to the largest member alignment. Here largest member is int, usually 4-byte aligned. So total struct size should be a multiple of 4.
