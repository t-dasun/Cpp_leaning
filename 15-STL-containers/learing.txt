std::array 
static array, support iterators, know about size
provide random access, cannot grow (create compile time), can use with c functions

arr.data(); // return pointer to standerd array that can pass to c functions

std::vector
behave like dynamic array
grow automaticaly
efficent add and remove at end
provide random access
not good for insersion and deletion (middle)
std::vector<int> vec {1,2,3,4,5};
auto itr = vec.begin();

vec.insert(vec.begin()+x, value) // insert value at x location from begin (not efficent)
vec.erase(vec.end-x); remove element to the 3rd from end (not efficent)

vec.pop_back()// remove last element

std::forward_list
implemeted as one-way linked list 
small memory footprint
efficent for delete/insertion
does not provide size
elements added at the front
std::forward_list<int> listc {1,2,3,4,5};
no push_back, we have push_front
we access listc 1,2,3,4,5 in reverse order 
listc.insert_after(listc.begin(),10) // add value 10 to seconnd position
lestc.erase_after(listc.begin()) // erase second element
